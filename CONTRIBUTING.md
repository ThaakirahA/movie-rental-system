# Contributing to Aura Reels Movie Rental System

Thank you for your interest in contributing to the Aura Reels Movie Rental System.

## Prerequisites

Before contributing, ensure you have:

* Node.js installed
* Git installed
* A GitHub account
* Visual Studio Code (recommended)

## Getting Started

1. Fork this repository.
2. Clone your fork locally.

```bash
git clone https://github.com/YOUR-USERNAME/movie-rental-system.git
```

3. Install dependencies.

```bash
npm install
```

4. Run tests.

```bash
npm test
```

## Coding Standards

* Follow JavaScript best practices.
* Use meaningful variable and function names.
* Write clear comments where necessary.
* Ensure all tests pass before submitting changes.

## Working on Issues

1. Select an issue labeled:

```text
good-first-issue
```

2. Create a new branch.

```bash
git checkout -b feature/issue-name
```

3. Implement your changes.

4. Add or update tests.

## Submitting Pull Requests

1. Push your branch.

```bash
git push origin feature/issue-name
```

2. Open a Pull Request.

3. Include:

   * Description of changes
   * Related issue number
   * Testing performed

4. Wait for review and approval.

## Reporting Bugs

Please include:

* Expected behaviour
* Actual behaviour
* Steps to reproduce
* Screenshots if applicable

Thank you for contributing to Aura Reels.
